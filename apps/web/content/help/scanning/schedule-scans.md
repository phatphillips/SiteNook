## How do I set a schedule?

1. Open the site → **Settings** (or scan configuration).
2. Choose a schedule such as **daily** or **weekly**.
3. Save. SiteNook stores the next run time and the scanner picks it up when due.

## Will schedules overlap?

If a previous run is still processing, the scheduler typically waits. Prefer canceling stuck runs rather than stacking many queued jobs.

## Tips

- Start with daily for critical public sites, weekly for low-change interiors.
- Align schedules with deploy windows so trends reflect production changes.
