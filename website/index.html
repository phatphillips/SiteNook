SiteNook
Install GitHub

Open source · Self-hosted · MIT

Accessibility and QA monitoring you run yourself

SiteNook crawls your sites with Playwright and axe-core, stores results locally in PocketBase, and shows WCAG issues, broken links, spelling, and SEO checks in a Nuxt dashboard.

Get started View on GitHub

What you get

  • Accessibility — axe-core WCAG findings with history
  • QA — broken links, spelling, inventory
  • SEO — crawl-based checks
  • Policies — custom content rules
  • Schedules — recurring scans on your timetable
  • Your machine — data stays in your Docker volume

Install

git clone https://github.com/phatphillips/SiteNook.git
cd SiteNook
cp .env.example .env
# set PB_ADMIN_* and APP_USER_*
docker compose up -d --build

Open http://localhost and sign in with your app user.
